# Zuid-Holland-Nieuws
112 Zuid-Holland is een regionaal nieuwsplatform dat verslag doet van actuele incidenten en hulpverleningsinzetten in Zuid-Holland. Met nieuwsberichten en eigen beeldmateriaal informeren wij inwoners over onder andere branden, verkeersongevallen en politie-inzetten. Wij staan voor betrouwbare, duidelijke en professionele berichtgeving uit de regio.
